  • Family size considerations

6.3 Train Data Service

Purpose: Manage train schedules via Firebase Remote Config

Features:

  • Firebase Remote Config integration
  • Local caching with SharedPreferences
  • Automatic updates every 12 hours
  • Fallback to default data
  • Search by origin and destination
  • Filter by travel class availability

Data Update Flow:

  1. Fetch from Firebase Remote Config
  2. Parse JSON train data
  3. Cache locally for offline access
  4. Serve from cache if network unavailable

9. Setup & Installation

9.1 Prerequisites

  • Flutter SDK 3.11.0 or higher
  • Dart SDK
  • Android Studio / VS Code
  • Firebase account
  • Android/iOS development environment

9.2 Dependencies

dependencies: flutter: sdk: flutter cupertino_icons: ^1.0.8 http: ^1.6.0 cached_network_image: ^3.3.0 firebase_core: ^2.24.2 firebase_remote_config: ^4.3.8 shared_preferences: ^2.2.2

9.3 Installation Steps

  1. Clone Repository:
    git clone [repository-url] cd travelbuddyai
  2. Install Dependencies:
    flutter pub get
  3. Firebase Setup:
    • Create Firebase project
    • Add Android app with package name: com.example.travelbuddyai
    • Download google-services.json to android/app/
    • Update firebase_options.dart with real API keys
  4. Configure Remote Config:
    • Go to Firebase Console → Remote Config
    • Add parameter: train_schedules_json
    • Paste train data JSON
    • Publish changes
  5. Run Application:
    flutter clean flutter run

9.4 Build for Production

# Android APK flutter build apk --release # Android App Bundle flutter build appbundle --release # iOS flutter build ios --release
